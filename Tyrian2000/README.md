# Tyrian2000

Place `tyrian2000.zip` here: the Tyrian 2000 data files, released as
freeware, from <https://www.camanis.net/tyrian/tyrian2000.zip>.

The archive is not checked in; `.gitignore` in this folder excludes it.

To play with it, extract the game files into a `data` directory next to the
executable (with lowercase filenames), or start the game with
`--data=DIR`.  `get_data.sh` in the top directory downloads and extracts the
same archive into `data/`.
